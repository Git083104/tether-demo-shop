# Tether Demo Shop

A tiny storefront with planted external references, used to demo Tether.

Every `tether-demo-*` name is fictional and chosen to be unregistered.
The deploy and release workflows are disabled (`if: false`, manual trigger only) so GitHub never runs the planted `curl | bash` line.
Nothing here is meant to be built or deployed.
